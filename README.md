# ElectricSplash

## About ElectricSplash

This project is for people who would like someone silent, and sometimes joke
on about for minutes no end. This project is reasonably bad at sports, so if
you want an ego boost, you can play sports with this project.

This project was made originally for mathematics, but it soon evolved to
computer science.

## Usage

For regular people, you can meet him in his natural habitat of Discord,
GitHub, and Roblox.

You may initiate a conversation with a conversation packet:

```none
Hi! What are you doing?
```

The project may respond with a normal response. If you leave the project without
another packet for too long, it might start sending more messages detailing
his answer more, until it is exhausted of conversation packets.

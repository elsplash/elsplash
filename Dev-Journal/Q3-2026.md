## Project 3: GrindStone

### Prelude to GrindStone

Before we take any texts into this. We should know about Stonescript first.

Stonescript is a programming language that is used in a game named "Stone Story RPG", it is a very
rudimentary language. It is very simple, but there is one thing this programming language lacks.
That is a formatter and linter.

Stonescript also lacks one thing in particular, that is an actual syntax checker for the language,
both in-game, and outside editors of the Stonescript language. There is even a Discord chatroom
just for identifying code errors for beginners.

I have a feeling that some of the time, they really need an error checker in the game, or at least
for an editor, but this is just for one thing only. This is only for one way of creating Stonescript.
Which is external editors of Stonescript, this should be sufficient in identifying errors, and fixing
up some styles, or code designs that sould be correct.

This should help both the community, and the dev team extend the language itself. Which is my goal
for now.

I do intend to join their contributor program, but with my current plans, I will stay right in
my roadmap, and plan to join it as soon as I get into Senior High School.

### Creating the Flag handler

Making the flag handler was not so tricky, but I had to make some sacrifices. First off, I made only
one type of flag get the GCC style flags like the optimization flag for GCC, `gcc -O3 main.c`. The
flags I picked were the Linter and Formatter Modes, only the shortened flags work, `./Grindstone -L2`.
They do still accept these kind of flags, so don't worry: `./Grindstone -L 2 --formatter-mode 1`.

I also got some debug flags setup. So the testing should be intuitive.

By this point, I've made pretty great progress in the script. It's like almost finished, all I have
to do is edit, and create the voice-overs. It's pretty great.
